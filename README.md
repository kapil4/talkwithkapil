# Talk with Kapil website

The live site is **https://www.talkwithkapil.com**, built 7 November 2026 to replace the GoDaddy Airo site.
It's a plain one-page website with no monthly cost. GitHub Pages hosts it for free from this repository (`kapil4/talkwithkapil`, branch `main`).

## What's where

| Path | What it is |
|---|---|
| `tools/build.py` | **The source.** All the words, prices, links and FAQs live here. Edit this, then run it. |
| `index.html` | The page itself. It's generated by `tools/build.py`, so don't edit it by hand. |
| `style.css` | Colours, fonts and layout (gold, navy and maroon). |
| `img/` | Kapil's photos, the logo mark, the share image (`og.jpg`) and the debut video poster. |
| `fonts/` | Poppins and Lora, hosted with the site (no Google Fonts). |
| `about/`, `services/`, `booking/`, `contact/`, `kundali/`, `nadi/`, `blog/`, `numerology/` | Small pages that send old Airo links to the right part of the new page. |
| `404.html` | The "page not found" page. |
| `CNAME` | Tells GitHub the site's domain: `www.talkwithkapil.com`. |
| `_config.yml` | Keeps `README.md`, `CLAUDE.md` and `tools/` off the public site. |

## How to change something

1. Edit `tools/build.py`: prices are in `SERVICES`, questions in `FAQ`, the WhatsApp messages in `WA_*`, and the page text in `HTML`.
2. Run `python3 tools/build.py`. This rewrites `index.html`, the redirect pages, `404.html`, `robots.txt` and `sitemap.xml`.
3. Commit and push to `main`. GitHub publishes it in about a minute.
